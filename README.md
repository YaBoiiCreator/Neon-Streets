HOW TO PLAY
-----------
1. Double-click run.bat.
2. Create an account (Sign up) or log in.
3. Click start and play.
 
On foot:   WASD move | Shift run | Q/E or drag = camera
           Space shoot | F enter car
Driving:   W/S gas and brake | A/D steer | Space handbrake | F exit
 
You need an internet connection. The game loads the three.js graphics
library from cdnjs.cloudflare.com (a public code library host).
 
 
IF THE GAME LAGS
----------------
- Close other browser tabs and heavy programs.
- In Edge: Settings > System and performance > turn ON
  "Use graphics acceleration when available", then restart Edge.
- Close all Edge windows, then double-click Lag-Preventer.py.
- Make the browser window smaller (fewer pixels = faster).
 
 
PRIVACY - WHAT THE GAME DOES WITH YOUR INFO
-------------------------------------------
- Accounts and game saves are stored in your own browser on your own
  computer. Passwords are scrambled (hashed) before being stored.
- The ONLY time anything is sent out is the "Forgot password?" form.
  It sends your account email, username, and the reason you typed to
  the game owner through formsubmit.co so they can follow up.
  Nothing else is sent.
- The game does not install anything, read your files, or run
  anything outside your browser.
